## Learning roadmap

I'm working toward more complete AI applications, from understanding model inputs to evaluating their outputs.

```text
FOUNDATIONS          APPLICATIONS          RETRIEVAL             RELIABILITY
Python + tokens  →   Prompts + APIs    →   Embeddings + RAG  →   Evaluation + testing
```

- **Current work:** tokenizer training, LLM API integration, and prompt experiments.
- **Next learning goals:** semantic search, document question answering, and grounded responses.
- **Longer-term direction:** tool-using workflows, repeatable evaluations, and deployment practices.

The roadmap describes my learning direction; completed work is documented in the linked repositories.

<details>
<summary><strong>How I approach a project</strong></summary>

<br />

1. **Define the problem.** Start with a specific question and a useful outcome.
2. **Build a small working version.** Keep the first implementation understandable.
3. **Inspect the results.** Look at examples, errors, and edge cases.
4. **Document the process.** Record setup steps, decisions, and limitations.
5. **Improve deliberately.** Let observed results guide the next change.

</details>
